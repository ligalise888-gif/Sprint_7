# Sprint_7 — API-тесты сервиса Яндекс Самокат

Автотесты для API учебного сервиса Яндекс Самокат.
Документация API: https://qa-scooter.praktikum-services.ru/docs/

## Что протестировано

Основное задание:
- Создание курьера (POST /api/v1/courier)
- Логин курьера (POST /api/v1/courier/login)
- Создание заказа (POST /api/v1/orders) — с параметризацией по цветам
- Список заказов (GET /api/v1/orders)

Дополнительное задание:
- Удаление курьера (DELETE /api/v1/courier/:id)
- Принятие заказа (PUT /api/v1/orders/accept/:id)
- Получение заказа по номеру (GET /api/v1/orders/track)

Всего 26 тестов (25 passed, 1 xfailed). В каждом проверяется код ответа и тело. Тесты независимы, тестовые данные создаются перед тестом и удаляются после.

## Установка

Установить зависимости: pip install -r requirements.txt

## Запуск тестов

Запустить все тесты: pytest

Запустить с генерацией данных для Allure: pytest --alluredir=allure_results

Посмотреть отчёт: allure serve allure_results

## Найденные дефекты и расхождения с документацией

В ходе ручной проверки в Postman и прогона тестов обнаружены отличия фактического поведения API от документации:
- Логин несуществующего курьера возвращает 404 (в документации 400).
- Получение заказа по несуществующему track возвращает 404 (в документации 400).
- Удаление курьера без id и с несуществующим id возвращает 404 (в документации 400).
- Логин курьера без пароля не возвращает 400 — сервер зависает и отвечает 504 Gateway Timeout (в документации 400). Это дефект API. Соответствующий тест помечен pytest.mark.xfail с указанием причины.

Тесты написаны под фактическое поведение сервиса.
